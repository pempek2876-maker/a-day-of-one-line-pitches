A program that writes one 150-character pitch line for a friend who has never coded: "Tell it your idea in plain words and watch an AI agent build your first app on make.fun — no code, no cost, just the thing you imagined, ready to try."

## Run it

```sh
node main.ts
```

The program scores 10 candidate pitches against the published judge brief (persuasion, clarity, truth, warmth, in that order), plays a 45-game round-robin tournament, and writes the winner — 100% win rate (9/9) — to `/output/entry.txt`.
